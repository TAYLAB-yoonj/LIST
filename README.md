# LIST
Microfluidic LIST platform, operational code

## Overview
This repository contains a collection of folders related to a software project, including:
- **AutoCAD Design**: Files and resources for AutoCAD designs, focusing on architectural and engineering blueprints.
- **GUI Code**: Codebase for the graphical user interface components to operate the LIST platform, built to enhance user interaction and experience.
- **Operational File for GUI**: Operational files supporting the GUI functionality, including configuration settings and runtime data.
- **Colony Tracking**: Tools and scripts for tracking colony and segmentation are aimed at monitoring and analyzing colony behavior.

## Structure
- `1_AutoCAD_Design/`: Contains design files, CAD templates, and documentation for creating detailed technical drawings. Includes sample projects and best practice guides.
- `2_GUI_Code/`: Includes source code for the GUI, written in modern web technologies, with modular components for easy maintenance and scalability. Includes setup instructions in the folder.
- `3_Operational_File_for_GUI/`: Houses operational data and configurations for the GUI, such as user preferences, log files, and database schemas to ensure smooth operation.
- `4_Colony_Tracking/`: Contains tracking scripts, data analysis tools, and visualization assets. Includes sample datasets and a guide for integrating with external tracking systems.
